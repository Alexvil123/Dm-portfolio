## 🏃 How to Run Locally

You can launch the site instantly using Node.js:

```bash
node server.js
```

Open your browser and navigate to:
```
http://127.0.0.1:5050/
```

Or simply double click `index.html` to open it in any browser!

## 🛠️ Personalization / Customization

- **Change Name / Title**: Edit `<span class="brand-name">` and `<h1 class="hero-title">` in `index.html`.
- **Update WhatsApp Number**: Modify the WhatsApp link in `index.html`:
  `href="https://wa.me/YOUR_PHONE_NUMBER?text=..."`
- **Update Email / Socials**: Change `kavin.growth@dmportfolio.com` and social links in the footer and direct contact rows.
- **Update Case Studies**: Modify the `caseDetails` object in `js/main.js` to showcase your own client campaigns and figures.
